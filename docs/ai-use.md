# Use of AI tools

The course policy allows AI tools with explicit acknowledgement. This file is that acknowledgement and is kept up to date during the project.

## Tools

- **Claude Code** (Anthropic): literature and technology survey, drafting code and tests, drafting documentation.
- **OpenAI Codex**: independent review of every change before it is pushed.

## How they are used

- Algorithms come from the cited papers, not from the tools. The tools help write and check the implementation.
- Every function has a test written before the implementation. Tests on synthetic signals with a known answer are the acceptance criterion, not the tool's output.
- Every change is read and understood by a team member before it is merged. Any part of the code can be explained by its author without the tool.
- AI review findings are verified before they are accepted.

## What is never sent to an AI tool

- Video, images or audio of any person.
- Recorded sessions, reference-device readings or any participant data.
